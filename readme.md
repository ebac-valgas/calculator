# 🧮 Projeto Calculadora

Script em **Python** que implementa uma calculadora simplificada para operações básicas.

---

## 📋 Pré-requisitos
- **Python 3** instalado em sua máquina
- Git instalado para clonar o repositório

---

## 🚀 Como utilizar

1. **Clone o repositório**
   ```bash
   git clone https://github.com/ebac-valgas/calculator.git

2. **Acesse a pasta do projeto**
   ```bash
   cd calculator

3. **Torne o arquivo executável**
   ```bash
   chmod u+x calculatora.sh

4. **Execute o script**
   ```bash
   .\calculatora.sh

## Funcionalidades
- Adição
- Subtração
- Multiplicação
- Divisão


# Executando a calculadora
.\calculadora.sh
